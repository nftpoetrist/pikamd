## 1. Tasarım dili: oyunlaştırılmış, okunaklı piksel sanatı

- **Tarz:** 8-bit / retro oyun estetiği, premium ve okunaklı. Kullanıcı "piksel tarzı ama okunabilir" istedi.
- **Zemin (2026-10-15, telif temizliği):** PikaMd'nin kendi koleksiyon kartlarından oluşan sıcak altın bir yığın (`web/public/bg/pikamd-cards.webp`, 2880×1416, 424 KB; eski Pokémon kartlı `background1.png` kaldırıldı). Kartlarda maskot (2026-10-25'ten beri kedi; arka plan aynı tohumla yeniden üretildi, kartların yeri ve sırası birebir aynı; "PikaMd No." kafa kartlarında 16×16 kafa yerine elinde sayfa tutan tam maskot, kart numarasına göre yarı PikaMd sarısı–yarı Arc mavisi, tersi ya da tamamen Arc mavisi), PikaGold sikkesi, dört köşeli parıltı, yönerge dosyaları ve mor/lacivert/yeşil özellik kartları; başlıklar genel adlar (üçüncü taraf ürün adı yok). `design/brand/background.mjs` ile üretilir (sitenin piksel haritalarını bileşenlerden okur, sabit tohumlu → aynı görsel; HTML sahnesi headless Chrome'da 2× çekilir). Efektler PikaStake'tekiyle aynı: `blur(2px)` + `scale(1.01)` (**2026-10-26'dan beri bulanıklık görsele gömülü**: `background.mjs` → `sharp.blur(3.5)`; CSS filtresi kalktı, görünüm piksel piksel karşılaştırıldı: 1440 / 1920 / 390 px'te ortalama fark < 2/255; dosya 430 → 202 KB), üstünde `rgba(4,2,0,0.35)` koyu katman, en üstte 40px silik sarı ızgara. Görsel yüklenene kadar `placeholder="blur"` (webp statik içe aktarmada Next otomatik üretir) + amber yedek zemin (asla siyah ekran olmasın).
- **Dil:** Sitedeki her metin İngilizce (ARCHITECTURE K18).

### 1.3 Piksel çerçeve tekniği (her yerde aynı)
- `border-radius` **yok**. Kenarlık 4 ayrı `box-shadow` ile çizilir (üst/alt/sol/sağ) → köşeler boş kalır → basamaklı 8-bit köşe.
- 8-bit kabartma: `inset 0 3px` açık ton (üst), `inset 0 -3px` koyu ton (alt).
- Butonlarda 3D taban: çerçevenin altından `--px-base` kadar görünen koyu şerit; `:active` olunca iner.
- Hareketler `steps(n)` ile (pürüzsüz değil, kare kare): yanıp sönen imleç, para/kalp animasyonu, hover.

### 1.4 Simetri ve boşluk kuralı (kullanıcı özellikle istedi)
- Çerçeveler kutunun **dışına** taşar. Öğeler arası aralık = **iki çerçeve + net boşluk** → çerçeveler asla birbirine değmez.
- Navbar ölçüleri `.navbar` üzerinde: `--px-b: 3px` (çerçeve), `--px-gap: 12px` (net boşluk), `--px-h: 34px` (yükseklik), `--px-base: 4px` (3D taban).
- Butonlar, linkler, ☰ butonu aynı yükseklikte; iki buton aynı iskelet (aynı çerçeve + aynı 3D taban).

### 1.5 CSS kuralları
- Bileşen stilleri **`@layer components`** içinde (yoksa Tailwind'in `hidden` / `md:hidden` gibi utility'lerini ezer).
- Dinamik değerler inline `style={{}}` (CLAUDE.md kuralı); sabit stiller `globals.css` sınıflarında.
- Kod yorumları İngilizce.
- **İmleç (2026-10-15, kullanıcı isteği):** yazıların üstünde imleç değişmez. `body { cursor: default }` tüm sayfaya miras kalır; metin yine seçilip kopyalanabilir (`user-select` kapatılmaz). Linkler ve butonlar el imlecini korur. Yazı yazılan alanlar (`input`, `textarea`, `contenteditable`) metin imlecini `@layer base`'de korur; bileşenin kendi imleci (`not-allowed`, `wait`…) her zaman kazanır. Ölçüldü: 6 sayfada metin imleci gösteren yazı yok, seçim çalışıyor.

### 1.6 Performans: hareket hafif kalır (2026-10-26, kullanıcı isteği: "GPU ısındı, estetikten ödün vermeden gereksiz yükleri kaldır")
Ölçüm yöntemi: headless Chrome (yazılım GPU'su SwiftShader, yani GPU işi = GPU sürecinin işlemci süresi) + `SystemInfo.getProcessInfo`, 6 sn, her şüpheli tek tek kapatılarak. Kurallar:
- **Sürekli hareket tam piksel adımlarla** (`steps()`), pürüzsüz değil: ekran saniyede 120 kez değil, yalnızca bir şey değiştiğinde güncellenir; yazı alt piksellerde titremez. Explore şeritleri her 50 ms'de 1 px (20 px/s; adım sayısı = kart sayısı × (kart + boşluk), `--lane-cards` / `--lane-card-px`), deniz aynı 50 ms saatinde (200 / 250 / 300 ms'lik adımlar).
- **Yalnızca `transform` / `opacity` canlandırılır.** Özel CSS değişkeni (`@property`) ya da SVG öğesi canlandırma: ana iş parçacığı her karede çalışır. Kediler artık doğrudan `transform` + öğedeki `steps(calc(round(down, 100cqw - 32px, 2px) / 2px))` (yine 2 px'lik adımlar, tümü ölçüldü); kart 004'ün veri pikselleri SVG `<rect>` yerine SVG'nin üstünde iki HTML kutusu (SVG'nin yüzlerce rect'i her adımda yeniden boyanıyordu).
- **Görünür etkisi olmayan filtre yok.** Explore kartlarının `backdrop-filter`'ı ekranda hiçbir şey değiştirmiyordu (şerit ve rafta piksel farkı 0; şeridin kenar maskesi yeni bir backdrop kökü) → `.arc-sea .md-card` için kapalı. Arka plan bulanıklığı görsele gömülü.
- Sonuç (1440×900, 60 Hz): Explore GPU %19,8 → %7,2, sayfa %5,6 → %3,4; ana sayfa sayfa yükü %11,1 → %6,3 (GPU ~%15: kedilerin ve parıltıların küçük alanlı adımları; yazılım GPU'su her adımda tüm ekranı birleştirir, gerçek GPU yalnızca değişen alanı). Diğer sayfalar ~%2. Yeni animasyon eklerken: önce bu ölçüm.

## 6. Geliştirme ortamı
- Uygulama `web/` klasöründe: **Next.js 16.4** (App Router, Turbopack, `cacheComponents`), React 19.3, Tailwind v4.
- Sunucu: `cd web && npm run dev -- -p 3001` → **http://localhost:3001** (3000 portu kullanıcının başka bir projesine ait; ona dokunma).
- Tailwind **PostCSS** üzerinden (`postcss.config.mjs`, `@tailwindcss/postcss`). Eski `@tailwindcss/turbopack` loader'ı CSS değişikliklerini izlemeyi bırakıyordu → kaldırıldı. `turbopackFileSystemCacheForDev: false`.
- Sunucuyu yeniden başlatırken **sadece** 3001'i dinleyen ve cwd'si `PikaMd/web` olan süreci durdur. `pkill -f "next dev"` kullanma (kullanıcının diğer uygulamasını kapattı).
- Bu Next sürümü eğitim verisinden farklı: kod yazmadan önce `web/node_modules/next/dist/docs/` içindeki ilgili rehbere bak (`web/AGENTS.md`). Örn. `next/image`'da `priority` yerine `preload`.
- Testler: `cd web && npm test` (2026-10-18 itibarıyla 121: tarama ve düşmanca girdi süreleri, MCP, SIWE/oturum, beğeni, arama, yayın, PGlite şema testleri) · dev sunucu açıkken `npm run mcp:smoke` (60 kontrol) ve `npm run auth:smoke` (48 kontrol). Bağış: gerçek Arc testnet'te headless Chrome + EIP-6963 test cüzdanıyla 37 kontrol (2026-10-18, ARCHITECTURE §7.5). 2026-10-15'te tüm sayfalar dev + production build'de masaüstü ve 390px'te headless Chrome'la gezildi (konsol hatası, CSP ihlali, taşma yok). Cüzdan akışı headless Chrome'da EIP-6963 test cüzdanı enjekte edilerek denendi (imzayı CDP binding'iyle Node atar); arama da tarayıcıda uçtan uca denendi (masaüstü + 390px).
- **Git:** repo kökte (`PikaMd/`). Her iş kendi dalında (`feat/…`), main'e birleştirme kullanıcı onayıyla. Gizli dosyalar (`.env*`, `web/.data/`) git dışında; şablon `web/.env.example`.
- Doğrulama alışkanlığı: CSS değişikliği sonrası sunulan CSS chunk'ında yeni kuralı ara; görseli headless Chrome ile kontrol et (pencere en az ~500px genişlik açar; mobil için CDP `Emulation.setDeviceMetricsOverride`).
